my websites

tab to sheetmusic

paste a songsterr link or search for a song, and it turns the tab into sheet music you can print: standard notation, tab, or both. it plays the song back too, with a loop and a speed trainer for practicing, and it can export guitar pro and midi files.

open it » source code

pigeon palgames

a helper for gamepigeon, the imessage games. it finds every word in word hunt, anagrams and word bites, works out where the ships probably are in sea battle, and has bots for chess, checkers, four in a row and more. 13 games in total, and it works offline.

play it » source code

downloads

remapwindows

a key remapper for windows, built on autohotkey v2. each profile only runs while one of its programs is the active window. it comes with a profile for hotline miami that turns e into right click, which helps a lot on a laptop.

get it on github »
